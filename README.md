# suhail. — Mohammed Suhail Portfolio Website 🚀

A modern, responsive, and high-performance personal portfolio website built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

Featuring interactive milestones timeline, dynamic multi-language intro reveal animation, sticky Mac OS mockup browser preview, dedicated multi-picture certificate modals, and 1-click ATS-compliant resume download.

---

## 🌟 Features

- **Dynamic Preloader Animation**: Full-screen intro cycling through multilingual greetings (`Hello` ➔ `السلام عليكم` ➔ `[Random World Languages]` ➔ `suhail.`) with smooth curtain lift and full Light/Dark theme support.
- **Milestones & Projects Roadmap**: Organic SVG curved map path with synchronized sticky Mac OS mockup preview window.
- **High-Definition Gallery Modals**: Prev/next navigation, image zoom, captions, and thumbnail quick-switcher for awards and hackathon certificates.
- **Direct 1-Click ATS Resume Download**: Integrated standard single-page Harvard/Stanford ATS-compliant resume (`Mohammed_Suhail_Resume.pdf`).
- **One-Click Email Copy**: Dual copy cards for Gmail and Outlook with confetti feedback.
- **Clean Responsive Architecture**: Mobile-first design adapting seamlessly from 320px mobile screens to 4K ultra-wide displays.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer-motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Effects**: Canvas Confetti, Aceternity Spotlight

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mohammedsuhail0/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)
